## 存檔備查（不入 OFFICIAL，考據用途）

- 《康熙字典》kanripo 繁体全文（`download/kangxi/`，42 卷 299.5 万字符，探针 5/5 净）——**2026-09-08 历史正当性验证**：3,091 个拦截简体字在康熙原文仅出现 1 字（飞，且为《说文》徐注构件描述「上旁飞者象鸟颈」，非独立字头，证据不足维持拦截——**09-08 改判：飞移入 WHITELIST 單字放行、組詞攔**）——拦截集字形经 1716 年文本背书，确系现代简化产物。原文存档供考据引证。

- 《說文解字注》（段玉裁，殆知閣儒藏/小學，4.4M）、《說文解字系傳》（徐鍇，978K）——`download/shuowen_zhu/`。
  **注文含後世學者字形考辨，正是栀案（WHITELIST 定案）的證據來源**；但文本被殆知閣整體簡體化（探針 6/9 含、濾簡 1,975 字）且混入日系字形（凧枩氱繊），全量簡形過濾後超表僅 3+6 字、可放行攔截字 0——不具備出典表資格，僅作考據原文存檔（2026-09-08）。說文出典繼續由維基文庫白文版（8,574 字）代表。
