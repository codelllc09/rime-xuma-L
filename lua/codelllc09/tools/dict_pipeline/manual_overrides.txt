# 人工次序覆蓋表，兩種語法：
#   兩詞：  「詞A > 詞B」       ＝交換兩詞頻分（僅當前序反時觸發；A 順帶壓過夾在中間者）
#   名次：  「A > B > C > D」    ＝成員現有分數按名次重排（None 無頻詞可參與，按最低合成）
# 共同約束：全員同碼組、已在詞庫；語料更新後若自然滿足則自動退役（印「已滿足次序」）
# 詞形寫詞典形（繁體）；繁簡同形詞隨意。僅同碼詞有競爭，非同碼會警告跳過
# 來歷示例：快感(口語源反超)壓過快捷(書面語高)——2026-09 用戶書面語感修正
快捷 > 快感
存放 > 苗族
簡化 > 簡偁
